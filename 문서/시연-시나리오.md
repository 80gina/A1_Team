## 2. 예상 질문과 답변

### 기술 질문

| 질문 | 답변 |
|---|---|
| **왜 SQLite인가요?** | 기간·카테고리·키워드로 조건 조회가 필요했습니다. 파일 하나가 곧 DB라 설치도 필요 없고 파이썬에 내장돼 있습니다. |
| **raw와 clean을 왜 나눴나요?** | 정제 규칙이 틀렸을 때 재수집 없이 정제만 다시 돌리기 위해서입니다. 실제로 번개장터 오분류 때 재요청 0회로 고쳤습니다. |
| **4xx와 5xx를 왜 다르게 다루나요?** | 4xx는 제 잘못이라 100번 해도 같습니다. 5xx는 서버 사정이라 기다리면 풀립니다. 지수 백오프로 2·4·8초 늘려가며 재시도합니다. |
| **재시도가 실제로 효과가 있었나요?** | 네. AI 요약 중 ReadTimeout이 한 번 났는데 재시도로 성공해서 최종 16건 성공 0건 실패였습니다. |
| **JSON 스키마를 왜 강제하나요?** | 자유 형식으로 받으면 '키워드 5개'를 프로그램이 꺼낼 수 없습니다. 차트와 리포트에 값을 넘겨야 하니까요. |
| **감성에 enum까지 건 이유는?** | "약간 긍정적입니다" 같은 답이 오면 집계가 깨집니다. 셋 중 하나여야 차트를 그릴 수 있습니다. |
| **모듈을 왜 7개로 나눴나요?** | 바뀔 이유가 다르기 때문입니다. 모델을 바꾸면 `ai_client.py` 만, 출력 형식이 늘면 `reporter.py` 만 손댑니다. `cleaner.py` 는 순수 함수라 네트워크 없이 시험할 수 있었습니다. |
| **한글 폰트는 어떻게 처리했나요?** | 설치된 폰트 목록에서 맑은 고딕부터 순서대로 찾아 지정합니다. 못 찾으면 경고만 남기고 진행합니다. `unicode_minus`도 껐습니다. |
| **크롤링 정책은 어떻게 지켰나요?** | robots.txt를 미리 확인했고, 1초 지연, User-Agent 명시, `--limit` 제한, 그리고 `--target clean` 으로 **필요한 기사에만** 요청합니다. 158건 중 39건만 방문했습니다. |
| **API 키는 어떻게 보호했나요?** | `.env` 에 두고 `.gitignore` 에 등록했습니다. GitHub 추적 파일 0건을 확인했고, 로그에는 `AQ.A********` 로만 남습니다. |

### 곤란할 수 있는 질문 — 정직하게 답할 것

| 질문 | 답변 |
|---|---|
| **정제 통과율이 10%밖에 안 되는데요?** | 종합 일간지에서 음식·여행 기사만 골라낸 비율입니다. 낮은 게 문제가 아니라 필터가 일하고 있다는 뜻입니다. 다만 소스를 음식·여행 전문 매체로 바꾸면 이 비율은 크게 올라갑니다. |
| **분류가 틀린 게 있던데요?** | 네, 16건 중 2건입니다. 정밀도 87.5%로 실측했고 보고서에 적었습니다. 키워드 방식의 한계이고, `require_any`·`exclude` 조건으로 한 번 좁혔지만 완전하지 않습니다. 다음 단계는 AI 분류입니다. |
| **AI가 코드를 다 짜준 거 아닌가요?** | AI를 도구로 썼습니다. 다만 AI가 제안한 것을 그대로 쓰지 않은 지점들이 있습니다. 본문 추출에 대체 경로를 요구했고, 차트 색을 되돌렸고, 모델 전환 조건을 404로 좁혔습니다. 실행과 확인, git 작업은 전부 직접 했습니다. |
| **커밋 번호에 8번이 없는데요?** | 분류 규칙 보정분이 커밋 9 메시지에 함께 올라갔습니다. 이미 푸시된 기록을 강제로 덮어쓰는 게 더 위험하다고 판단해 그대로 뒀습니다. |
| **데이터가 16건이면 너무 적지 않나요?** | 수집한 건 158건이고, 주제에 맞는 게 16건입니다. 소스를 늘리거나 수집 기간을 늘리면 바로 증가합니다. `config.json` 의 `sources` 에 항목을 추가하면 됩니다. |

## 3. 시연 중 사고 대응

| 상황 | 대응 |
|---|---|
| **인터넷이 끊겼다** | `fetch` 를 건너뛰고 `list` → `analyze --show` → `report` 로 진행. 이미 모은 데이터로 전부 시연 가능하다 |
| **AI 호출이 실패한다** | `analyze --show` 로 저장된 결과를 보여준다. "분석 결과를 별도 저장하는 이유가 이겁니다"라고 넘긴다 |
| **차트 한글이 깨졌다** | 미리 만들어둔 PNG를 탐색기에서 연다 (0-3에서 준비) |
| **명령어가 안 먹는다** | `(.venv)` 가 프롬프트에 있는지 먼저 확인 |
| **시간이 부족하다** | 6:30~8:30(리포트) → 9:30(Git)로 건너뛴다. 보너스 구간을 생략 |
| **시간이 남는다** | `show <ID>` 로 분류 근거·본문 출처를 보여주거나, `daily.ps1` 스케줄링을 설명 |
