## 5. 누락 시 재현 방법

평가 중 무언가 빠졌다는 지적을 받으면 아래 명령으로 즉시 만들 수 있다.

| 빠진 것 | 재현 명령 | 소요 |
|---|---|---|
| 차트 PNG | `python main.py report` | 3초 |
| 리포트 파일 | `python main.py report --save --format md` | 3초 |
| 엑셀 파일 | `python main.py export --format excel` | 2초 |
| CSV / JSONL | `python main.py export --format csv` | 2초 |
| 데이터 전체 | `python main.py fetch --limit 50` → `clean` → `summarize` | 3분 |
| 감성 데이터 | `python main.py sentiment --limit 20` | 25초 |
| 인사이트 | `python main.py analyze` | 10초 |
| **전부 한 번에** | `powershell -ExecutionPolicy Bypass -File .\daily.ps1` | 2분 |

> `data/bapsang.db` 를 지우고 처음부터 돌려도 **전체가 재현된다.**
> 이것이 파이프라인을 명령별로 나눈 이유다.
