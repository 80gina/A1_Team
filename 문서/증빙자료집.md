## 구간 B — 수집 (커밋 3~5)

### 06_fetch.png

**찍은 것** `python main.py fetch --limit 10` 실행 화면
**증명하는 것** RSS 3종에서 각 10건씩 수집해 raw에 저장. 소스별 건수가 집계된다.
**요건** 2 (방법 1 — RSS)

### 07_dedup.png

**찍은 것** 같은 명령을 두 번째 실행한 화면
**증명하는 것** `0건 저장, 30건 중복 건너뜀` — 같은 기사를 두 번 저장하지 않는다. `url UNIQUE` + `INSERT OR IGNORE` 로 DB가 걸러낸다.
**요건** 3 (중복 처리 skip)

### 08_crawl.png

**찍은 것** `fetch --method crawl --limit 5` 실행 화면
**증명하는 것**
```
[1/5] ID=1 본문 1182자 확보 — 선택자 div.art_body
[4/5] ID=4 본문 4339자 확보 — 선택자 div.art_body
```
크롤링으로 본문을 확보했고, **어느 경로로 찾았는지**가 로그에 남는다. 5건 전부 1단계 선택자로 성공.
ID=4가 4,339자 — RSS 요약문 203자와 비교하면 **왜 크롤링이 필요한지**가 이 숫자 하나에 들어 있다.
**요건** 2 (방법 2 — 크롤링), 과제목표 1

### 09_branch_commit.png

**찍은 것** `feature/crawl` 브랜치에서 커밋한 화면
**증명하는 것** `[feature/crawl 19a841d]` — main이 아니라 브랜치에 커밋이 쌓였다.
**요건** Git 실습 (branch)

### 10_merge.png

**찍은 것** `git log --oneline --graph` 결과
**증명하는 것**
```
*   1d1835e 커밋5: feature/crawl 병합
|\
| * 19a841d 커밋4: 크롤링 수집기
|/
* 0b47046 커밋3: RSS 수집기
```
`|\` `|/` 모양 — 갈라졌다 합쳐진 기록. `--no-ff` 로 병합해 브랜치 이력이 남았다.
**요건** Git 실습 (merge)

## 구간 C — 정제 (커밋 6, 8)

### 11_clean.png

**찍은 것** `python main.py clean` 실행 화면
**증명하는 것**
```
정제 완료: 19건 저장, 132건 제외
  제외 사유 - 주제 밖(음식·여행 아님): 130건
  제외 사유 - 본문·요약 모두 없음: 2건
```
정제 5규칙이 동작하고, **제외 사유가 종류별로 집계**된다. 카테고리 5종이 모두 나왔다.
**요건** 3 (정제), 7 (품질 지표의 원자료)

### 13_rebuild.png

**찍은 것** `python main.py clean --rebuild` 실행 화면
**증명하는 것**
```
재구축 모드: 규칙에 더는 맞지 않는 기사는 clean 에서 제거됩니다.
재구축: 규칙에 맞지 않게 된 6건을 clean 에서 제거했습니다.
```
**'번개장터' 오분류를 발견한 뒤 규칙만 고치고 정제만 다시 돌린 기록.**
뉴스 사이트 재요청은 0회. raw/clean 분리의 값어치가 드러난 화면이다.
**요건** 3 (raw/clean 분리, upsert), 과제목표 3

## 구간 D — AI (커밋 7, 9)

### 12_summarize.png / 12_1_summarize.png

**찍은 것** `python main.py summarize --unsummarized` 실행 화면
**증명하는 것**

- `(1348자 → 121자)` — 본문을 요약했다
- `요약 완료: 16건 성공, 0건 실패`
**요건** 4 (AI 요약), 9 (키 관리)

### 14_resummarize.png

**찍은 것** 본문을 더 확보한 뒤 `summarize --all` 로 재요약한 화면
**증명하는 것**
```
[WARNING] AI 연결 실패 (1/3): ReadTimeout. 2초 뒤 재시도합니다.
[13/16] ID=19 요약 완료 (1534자 → 212자)
...
요약 완료: 16건 성공, 0건 실패
```
**실제 타임아웃이 발생했고 재시도로 살아났다.** 오류 처리가 실전에서 1건을 구한 기록.
이전의 `203자 → 148자` 가 `1534자 → 212자` 로 바뀐 것도 함께 보인다.
**요건** 2·4 (오류 처리), 과제목표 2

### 15_analyze.png

**찍은 것** `python main.py analyze` 실행 결과
**증명하는 것** 16건을 종합해 5개 항목이 구조화되어 나왔다.
```
[주요 트렌드] 추석 연휴와 단기 휴가를 맞아 …
[핵심 키워드] 여수섬박람회, 역사여행, 관광기념품, 추석연휴, K푸드 …
[레시피 소재 제안] 한우 뭉티기 트리오 소스 플래터 / 여수 섬 밥상 해산물 솥밥 …
```
JSON 스키마를 강제했기 때문에 항목이 정확히 나뉜다. **레시피 소재 제안**이 이전 과제와의 연결 고리.
**요건** 5 (인사이트 분석), 과제목표 4

### 16_analyze_show.png

**찍은 것** `python main.py analyze --show` 실행 화면
**증명하는 것** **API를 호출하지 않고** 저장된 분석 결과를 다시 꺼냈다. `analyses` 테이블에 별도 저장된다는 증거.
**요건** 5 ("분석 결과가 저장되고 조회 가능하다")
